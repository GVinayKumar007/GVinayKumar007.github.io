# G Vinay Kumar — Portfolio

A responsive personal portfolio website for an AI/ML-focused B.Tech CSE student.

## Before publishing
Open `index.html` and replace:
- Email is already configured as `gvinaykumargundemoni@gmail.com`
- LinkedIn is already configured
- GitHub is configured as `https://github.com/GVinayKumar007`

You can also add your profile photo, resume, certificates, and more projects.

## Publish with GitHub Pages
1. Create a GitHub repository named `yourusername.github.io`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch** and choose `main` / root.
5. Your portfolio will be available at:
   `https://yourusername.github.io/`

## Suggested final domain
Once you have a GitHub Pages site working, you can later connect a custom domain such as:
`vinaykumar.dev` or `vinaykumar.ai`
